# Моделирование продуктовой компании

Веб-приложение для расчёта динамики 15 показателей продуктовой компании с учётом пяти внешних факторов. Основа модели — постановка задачи, матрица причинно-следственных связей и система уравнений из документа «Продуктовая компания.docx» до раздела «Решение системы дифференциальных уравнений».

По указанию пользователя примеры реализации из заключительной части документа не используются как требования. В частности, из них не берутся начальные значения, значения L*, таблица коэффициентов a₀…a₃, утверждение о нулевой степени полиномов и функции со скриншотов.

## Запуск

Используется Python 3.13. Если версия Python изменилась, создайте окружение заново.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py runserver
```

Приложение открывается по адресу http://127.0.0.1:5000/.

В PyCharm выберите существующий интерпретатор `.venv\Scripts\python.exe` и конфигурацию **Application**, затем нажмите **Shift+F10**. Конфигурация запускает `manage.py runserver` из корня проекта.

Для формирования PDF используется ReportLab; отдельная установка `wkhtmltopdf` не требуется.

## Данные сценария

Пользователь вводит начальные значения L₁…L₁₅, положительные масштабы L₁*…L₁₅*, начало и конец интервала расчёта, параметры внешних факторов и параметры функций влияния. Значения, не заданные в постановке, не подставляются из примеров другой реализации.

Нижние пороги предзаполнены значениями из раздела «Ограничения и допущения»:

| Показатель | Минимум |
| --- | ---: |
| L₁ — остаток денежных средств | 0,1333 |
| L₂ — выручка | 0,2333 |
| L₃ — прибыль | 0,15 |
| L₄ — активы | 0,27 |
| L₅ — численность | 0,16 |
| L₆ — конкурентоспособность | 0,16 |
| L₇ — объём продаж в натуральном выражении | 0,16 |
| L₈ — инновационность | 0,2 |
| L₉ — известность бренда | 0,2 |
| L₁₀ — материалоёмкость | 0,23 |
| L₁₁ — количество ремонтов | 0,32 |
| L₁₂ — износ оборудования | 0,3 |
| L₁₃ — налоги в бюджет | 0,2333 |
| L₁₄ — социальная сфера | 0,2666 |
| L₁₅ — экологичность | 0,1 |

Это именно нижние пороги, как они названы в задании. Для затратных показателей, например износа оборудования, экономическая трактовка нижней границы требует уточнения предметной модели. Программа не заменяет её самостоятельно верхним пределом и не объявляет компанию экономически несостоятельной только по результату этого критерия.

Интервал времени задаётся пользователем: 0 ≤ t₀ < t₁. Ограничение начала нулём связано с функцией √t; фиксированный интервал [0; 1] из примеров не навязывается.

## Внешние факторы

| Фактор | Функция и ввод |
| --- | --- |
| q₁ — курс валюты | a + b sin(ct + d); пользователь вводит a, b, c, d |
| q₂ — санкции | a + b sin(ct + d); пользователь вводит a, b, c, d |
| q₃ — эпидемия ковид | 0 при t ≤ 0,6; 0,3 при 0,6 < t ≤ 0,8; 0,4 при t > 0,8 |
| q₄ — штрафы на CO₂ | Ступенчатая функция; пользователь вводит моменты переходов и значения ступеней |
| q₅ — опыт специалистов | a√t + b; пользователь вводит a, b |

Для q₄ первая ступень начинается в t = 0, остальные моменты строго возрастают. Значение в момент перехода принадлежит новой ступени.

Для q₃ исправлены две неточности исходного рисунка: подпись q₄ отнесена к q₃ по заголовку и описанию эпидемии, а пересекающиеся условия t > 0,6 и t > 0,8 прочитаны как последовательные интервалы. Условие t = 0,8 относится ко второй ступени, как следует из строгого неравенства третьей.

## Уравнения и функции влияния

Общая форма уравнений: dLᵢ/dt = (Bᵢ − Dᵢ) / Lᵢ*. Bᵢ и Dᵢ строятся из положительных и отрицательных влияний согласно матрице задания и таблице уравнений. Строка матрицы задаёт изменяемый показатель, столбец — влияющий показатель или внешний фактор. Числа −1, 0, +1 обозначают знак связи, а не допустимые значения Lᵢ.

В постановке используются 98 функций влияния f₁…f₉₈, но их конкретный вид и численные параметры до раздела с примерами не определены. Поэтому полиномиальная аппроксимация — явное допущение реализации. Пользователь выбирает степень от 0 до 3 и вводит все активные коэффициенты каждой функции: f(x) = a₀ + a₁x + a₂x² + a₃x³. Для степени 0 вводится только a₀, для степени 1 — a₀ и a₁ и так далее. Числа из отвергнутой таблицы коэффициентов не используются как значения по умолчанию.

Формулы, матрица и подграфы доступны на странице `/documents`, чтобы структуру модели можно было проверить до расчёта.

## Границы и результаты

Решение не обрезается до [0; 1]. Множитель 1/Lᵢ* задаёт масштаб скорости изменения, но сам по себе не гарантирует, что решение останется в этом диапазоне. В постановке нет правила насыщения на границах или требования подменять вычисленные значения нулём и единицей.

Выходы за [0; 1] показываются в результатах как повод проверить параметры и область применимости модели. Нарушения заданных минимумов отмечаются отдельно. Доступны графики динамики, сравнение показателей с порогами, PDF-отчёт и экспорт результатов в JSON. Числа на графиках и в выгрузках должны соответствовать одному вычисленному решению.

## Проверка

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Воспроизводимый сценарий определяется всеми пользовательскими параметрами, а не только 15 начальными значениями. При сравнении разных расчётов сохраняйте также L*, коэффициенты функций влияния, внешние факторы, пороги и интервал времени.

## Редактируемый демонстрационный сценарий

Новая форма предзаполнена самостоятельным учебным примером, а не данными
отвергнутой реализации: L(t0)=0.6, L*=10, t от 0 до 1; f(x)=0.9+0.1x
(выбрана степень 2, a2=0). Для q1 заданы (a,b,c,d)=(0.4,0.1,2π,0),
для q2 — (0.35,0.05,2π,0), q5=0.1√t+0.4, q4 принимает уровни 0.05,
0.1 и 0.15 с момента t=0, t=0.5 и t=0.8 соответственно.
Минимальные пороги остаются из постановки. Все поля редактируются; удалённое
обязательное значение не подставляется автоматически при отправке.
Ссылка «Сбросить параметры» сбрасывает текущую форму к примеру.
Пользовательские значения после расчёта сохраняются отдельно.
