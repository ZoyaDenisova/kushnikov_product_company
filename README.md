# Моделирование продуктовой компании

Веб-приложение для расчёта динамики 15 показателей компании с учётом пяти внешних факторов. Результаты доступны в виде графиков, таблиц, PDF-отчёта и JSON-файла.

## Установка и запуск

Требуется Python 3.13. Выполните команды из корня проекта в PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py runserver
```

Откройте [http://127.0.0.1:5000/](http://127.0.0.1:5000/). Для остановки сервера нажмите `Ctrl+C` в терминале.

При последующих запусках достаточно последней команды. Если сменили версию Python, создайте виртуальное окружение заново и установите зависимости.

В PyCharm выберите интерпретатор `.venv\Scripts\python.exe` и конфигурацию **Application**, затем нажмите **Shift+F10**.

## Размещение на Render бесплатно

Проект подготовлен к запуску на Render: `.python-version` выбирает Python 3.13,
`wsgi.py` создаёт приложение, а `gunicorn.conf.py` настраивает порт из переменной
`PORT`, один процесс и таймаут 180 секунд. Расчёты выполняются последовательно,
чтобы не запускать несколько построений графиков одновременно на небольшом сервере.
Gunicorn устанавливается только на Linux/macOS; локальный запуск в Windows остаётся прежним.

## Выполнение расчёта

Форма открывается с готовым примером. Все параметры можно изменить.

Кнопка **«Случайные значения»** над вкладками одним нажатием заполняет все 15 показателей, параметры внешних факторов и коэффициенты 98 функций влияния. Выбранные интервал времени, степень полиномов и количество ступеней q₄ сохраняются. Фиксированный фактор q₃ остаётся заданным моделью.

Предзаполнение и случайные примеры подобраны для демонстрации динамики на интервале 0–1. Перед заполнением случайного примера сервер проверяет сходимость на выбранном интервале и принимает только варианты, у которых все показатели остаются в пределах [0; 1]. Если подходящий вариант не найден, поля сохраняют прежние значения и появляется сообщение. Эти параметры учебные и не являются оценками реальной компании.

1. Задайте интервал времени: `0 ≤ начало < конец`.
2. На вкладке **«Показатели»** заполните начальные значения, нормировку `L*` и минимальные пороги для L₁–L₁₅.
3. На вкладке **«Внешние факторы»** задайте параметры q₁, q₂, q₄ и q₅. Фактор q₃ фиксирован.
4. На вкладке **«Функции влияния»** выберите степень полиномов от 0 до 3. Для каждого L показано одно полное уравнение; его коэффициенты вводятся в квадратные поля внутри формулы. Параметры внешних факторов также вводятся прямо в их формулы.
5. Нажмите **«Рассчитать»**.

Все обязательные поля должны содержать числа. Нормировка `L*` должна быть положительной: чем она больше, тем медленнее изменяется соответствующий показатель при остальных равных параметрах. Минимальные пороги задаются в диапазоне от 0 до 1.

Функции влияния имеют вид `f(x) = a₀ + a₁x + a₂x² + a₃x³`. Выбранная степень определяет используемые коэффициенты: для степени 0 нужен только a₀, для степени 1 — a₀ и a₁ и так далее.

Формулы, матрица связей и подграфы показателей доступны по ссылке **«О модели и уравнениях»** на главной странице.

## Внешние факторы

| Фактор | Функция | Настраиваемые параметры |
| --- | --- | --- |
| q₁ — курс валюты | `a + b·sin(c·t + d)` | Смещение a, амплитуда b, частота c, фаза d |
| q₂ — санкции | `a + b·sin(c·t + d)` | Смещение a, амплитуда b, частота c, фаза d |
| q₃ — эпидемия COVID | 0 при t ≤ 0,6; 0,3 при 0,6 < t ≤ 0,8; 0,4 при t > 0,8 | Фиксированные значения |
| q₄ — штрафы на CO₂ | Ступенчатая функция | Моменты переходов и уровни ступеней |
| q₅ — опыт специалистов | `a·√t + b` | Темп роста a и начальное значение b |

Первая ступень q₄ начинается при t = 0. Времена следующих ступеней должны строго возрастать. В момент перехода действует значение новой ступени. Ступени можно добавлять и удалять в форме.

## Просмотр и сохранение результатов

На странице результатов доступны:

- график динамики с подписями L₁–L₁₅ у линий, переключением показателей и фильтром **«Финансы L₁–L₄»**; список **«Крупно»** показывает один показатель с автоматическим масштабом;
- ползунок времени для просмотра значений в выбранный момент;
- таблица начальных и конечных значений, порогов и времени первого нарушения;
- графики внешних факторов и пять лепестковых диаграмм состояния компании;
- кнопки **«PDF-отчёт»** и **«Скачать JSON»** для сохранения полного расчёта.

Показатели, опускавшиеся ниже заданного минимума, выделяются в таблице. Значения решения могут выходить за диапазон [0; 1]; они отображаются без обрезки. При несходимости расчёта проверьте коэффициенты функций и сократите интервал времени.

Выбор линий на графике не меняет содержимое PDF и JSON.

Чтобы пересчитать сценарий, нажмите **«Изменить параметры»**. После успешного расчёта его параметры восстанавливаются при открытии формы в том же браузере. Для возврата к начальному примеру используйте **«Сбросить параметры»** в форме или **«Новая модель»** на странице результатов.
